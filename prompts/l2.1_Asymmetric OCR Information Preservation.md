# 1. Research objective

Level 2.1 is a **generic temporal information-grouping problem**.

The objective is to group consecutive Level-1 candidate frames that belong to the same underlying information context, even when information progressively evolves between frames.

This is NOT specifically a PowerPoint-slide grouping system.

The method must be applicable to different types of video content, including:

* presentation slides
* mathematics/equations
* programming/coding screens
* whiteboards
* software/application interfaces
* educational demonstrations
* other visually evolving information

The implementation must therefore avoid slide-specific assumptions such as:

* PowerPoint-specific layouts
* fixed slide templates
* slide numbers
* assumptions that every group represents a "slide"

# 3. A2 — Improved asymmetric preservation method

A2 is the primary methodological improvement.

Replace the symmetric OCR Jaccard component with **Asymmetric OCR Information Preservation / Containment**.

For consecutive candidate frames:

Fi → Fi+1

Let:

Ti = OCR tokens in Fi

Ti+1 = OCR tokens in Fi+1

Calculate:

P_ocr(Fi → Fi+1) =
|Ti ∩ Ti+1| / |Ti|

Then:

L_ocr = 1 - P_ocr

Interpretation:

P_ocr measures how much of the information present in the earlier frame survives in the next frame.

This is intentionally directional.

Example:

F1 = A B C

F2 = A B C D E

Jaccard similarity:

3 / 5 = 0.60

But asymmetric preservation:

3 / 3 = 1.0

Therefore, adding information should not automatically be interpreted as losing the previous information.

This is the central motivation for A2.

---

# 4. IMPORTANT: Do not misuse Laplace smoothing

Do NOT claim that simple Laplace smoothing solves the short-token problem.

The formula:

(|intersection| + ε) / (|Ti| + ε)

still produces approximately 1.0 when Ti contains only one matching token.

Therefore, handle short OCR sequences explicitly.

Implement a configurable minimum-information guard.

For example:

* if the previous frame contains very few meaningful OCR tokens, OCR preservation should have reduced influence or be treated as unreliable;
* visual and layout evidence should then carry more influence.

Do NOT arbitrarily hard-code a scientifically unjustified value.

Make the minimum-token threshold configurable and expose it in the experiment configuration/UI.

Document this behavior.

---

# 5. Zero-token frames

Explicitly handle:

|Ti| = 0

Do NOT allow division by zero.

When the previous frame has no usable OCR tokens:

* OCR preservation is undefined/unreliable.
* Do not fabricate a preservation value that artificially forces SAME GROUP.
* Allow visual/layout signals to determine the transition.

Store an explicit indicator such as:

ocr_valid = false

so this case is visible in the report.

# 6. Template / boilerplate text

Do NOT simply delete repeated OCR tokens.

That would introduce an unjustified assumption.

However, repeated tokens across many frames may represent:

* headers
* footers
* watermarks
* channel names
* static UI elements
* presentation branding

If useful, implement an optional mechanism to identify frequently repeated tokens and down-weight them.

Requirements:

* configurable
* optional
* preserve the original OCR data
* do not destroy raw evidence
* do not assume all repeated text is boilerplate

The system should be able to compare results with and without this mechanism later.

---

# 7. Directional layout preservation

A2 should also use directional layout continuity.

For Fi → Fi+1, estimate how much of the previous spatial information/layout remains in the next frame.

Conceptually:

Layout Preservation =
preserved previous layout / previous layout

and:

Layout Loss =
1 - Layout Preservation

The exact implementation should use the existing OCR bounding-box/layout infrastructure where possible.

It must tolerate:

* small bounding-box shifts
* OCR detection noise
* text-box expansion
* additional text boxes
* new information appearing in previously empty regions

The objective is to distinguish:

1. same underlying context with additional information
2. same context with minor visual changes
3. genuinely new context
4. replacement of important content

Do not require exact bounding-box equality.

---

# 8. Keep SSIM in A2

A2 must still use visual continuity.

Do NOT remove SSIM.

This is important because OCR preservation can fail in cases such as:

F1:
Text A + Diagram X

F2:
Text A + Diagram Y

OCR may indicate strong preservation even though an important visual object has been replaced.

Therefore A2 should combine:

* asymmetric OCR information preservation
* directional layout preservation
* SSIM visual continuity
* temporal information

OCR preservation alone must NEVER determine the final grouping decision.

---

# 9. Do NOT hard-code an SSIM "force split"

Do not implement:

"If SSIM distance > 0.30 → automatically create a new group."

A large visual change is evidence of a possible boundary, but it is not automatically proof of a new underlying group.

Animations, handwriting, scrolling, code editing, and other evolving content can produce large visual changes while remaining within the same information context.

If an SSIM gate is useful, make it:

* configurable
* clearly documented
* experimentally adjustable

Do not tune it solely to make known examples pass.

---

# 10. B2 — A2 + ViT

Create a third experimental method:

B2 = A2 + ViT visual embedding distance

Use the existing ViT implementation if available.

Do NOT train ViT.

Cache embeddings.

Keep ViT modular and optional.

Configuration should allow:

* ViT enabled/disabled
* ViT weight
* ViT threshold/configuration

Do NOT assume ViT is better.

The research question is whether ViT adds useful information AFTER asymmetric information preservation has already been introduced.

Possible outcomes are:

* ViT improves grouping
* ViT has little effect
* ViT makes grouping worse

All are valid experimental results.
