## 1. Current Level 2 architecture

The thesis pipeline is:

Raw educational video
→ Level 1 candidate-frame selection
→ Level 2.1 information-unit grouping
→ Level 2.2 representative/keyframe selection
→ Level 3 OCR/layout/structured information extraction

Level 2.1 groups candidate frames that belong to the same underlying information unit.

Level 2.1 currently explores:

### A1 — Symmetric OCR similarity

For frames A and B:

$$
J(A,B)=\frac{|T_A\cap T_B|}{|T_A\cup T_B|}
$$

### A2 — Asymmetric information preservation / containment

$$
P(A\rightarrow B)=\frac{|T_A\cap T_B|}{|T_A|}
$$

This is intended to model progressive information accumulation:

A → A + B → A + B + C

rather than assuming that two frames must be symmetrically similar.

### B2

A2 + visual/layout evidence, potentially including ViT embeddings.

Level 2.2 should operate on the groups produced by Level 2.1.

# 3. Critically challenge the previous formulation

Analyze these weaknesses explicitly.

### Problem A — Circular/union universe

The union:

$$
U_G=\bigcup_i T_i
$$

contains every token that appeared at any point.

Therefore a final frame can be penalized simply because earlier instructional information was intentionally erased.

Determine whether this actually measures:

* pedagogical completeness,
* information preservation,
* transient information,
* or merely lexical coverage.

Explain the distinction.

### Problem B — Persistent vs transient information

Consider:

F1:
"Factor the equation"

F2:
"Factor the equation + set each factor to zero"

F3:
"x = 2, 3"

The final frame may not contain the derivation, but that does not automatically mean it is a bad keyframe.

Determine whether Level 2.2 should distinguish:

* persistent information,
* transient information,
* replaced information,
* newly introduced information.

If yes, formulate this mathematically.

### Problem C — Hard-coded K=1/K=2

Do not assume every group requires exactly:

* 1 frame, or
* 2 frames.

Consider whether Level 2.2 should instead solve:

> Select the smallest set of frames that provides sufficient information coverage.

If this is better, formulate an appropriate objective.

For example, investigate something conceptually like:

$$
K^*=
\arg\min_{S\subseteq G}|S|
$$

subject to:

$$
Coverage(S)\ge\tau
$$

But do NOT blindly use this equation. Determine whether it actually makes sense for this thesis and improve it if necessary.

### Problem D — Arbitrary threshold

The previous proposal used:

$$
\tau_{subsume}=0.70-0.95
$$

Determine how this threshold should be treated scientifically.

Possible options:

* validation-set selection
* sensitivity analysis
* fixed experimental grid
* manually justified threshold
* adaptive threshold

Recommend the most defensible approach.

### Problem E — Ground truth

Previous acceptance criteria said things such as:

* slides_AA → 33 groups → 33 keyframes
* MATH → 9–10 keyframes
* CODING → 12–13 keyframes

Do NOT treat these as ground truth merely because they are expected outputs.

Explain how actual Level 2.2 ground truth should be constructed.

# 4. Redesign the mathematical formulation

Develop a better Level 2.2 formulation.

The goal is:

> Given an information group produced by Level 2.1, select the minimum useful set of representative frames while preserving the information necessary to represent the instructional content of that group.

The formulation should ideally account for:

1. information introduced by a frame
2. information retained by later frames
3. information that disappears
4. persistent information
5. transient but potentially important information
6. final-state information
7. temporal order
8. OCR uncertainty / invalid OCR
9. optional visual evidence
10. avoiding unnecessary duplicate frames

Do not make it unnecessarily complicated.

I want a formulation that can actually be implemented and experimentally evaluated on my current hardware and codebase.

# 7. Domain generalization

The method must not be designed only for PowerPoint slides.

Consider:

### Slides

A → A+B → A+B+C

### Mathematics

equation → derivation → more derivation → final answer

### Coding

code → modified code → error → corrected code

### Whiteboard

partial derivation → expanded derivation → completed derivation

### Scrolling/terminal content

old content disappears because the viewport moves.

Determine which assumptions work across these domains and which must be domain-specific.

In particular, do NOT force layout similarity on scrolling content.
